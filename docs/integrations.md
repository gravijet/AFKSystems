# Integrations

Discord, Google login, mail delivery and payment processing require local credentials and provider configuration. Configure them through `.env` or the administration panel as appropriate.

Match callback URLs and webhook endpoints to your own instance. Validate payment webhook signatures before crediting an account. Use test credentials while checking payment flows.

The optional live viewer uses assets from an installed Minecraft client or downloads the corresponding assets from Mojang. Available viewer features depend on the client build.
