# AFKSystems documentation

Configuration is supplied through `.env` and the administration panel. Runtime data belongs under `data/` and is excluded from Git.

- [API](api.md): personal tokens and bot controls.
- [Architecture](architecture.md): panel, clients, agents and billing.
- [Integrations](integrations.md): Discord, Google login and payments.

Use a specific trusted proxy address or network when the panel sits behind a reverse proxy. Keep account credentials, bot tokens and payment keys in local configuration.
